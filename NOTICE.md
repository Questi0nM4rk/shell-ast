# Notice

shell-ast started as a fork of [un-ts/sh-syntax](https://github.com/un-ts/sh-syntax) (MIT), which wraps [mvdan/sh](https://github.com/mvdan/sh) (BSD-3-Clause). The Go processor and the TypeScript surface are rewritten. The WASM build pipeline comes from sh-syntax.

The shell parser, `mvdan.cc/sh/v3`, is BSD-3-Clause licensed: https://github.com/mvdan/sh/blob/master/LICENSE
